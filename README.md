# دنگ‌بان (DongBan)

دنگ‌بان یک Progressive Web App فارسی برای ثبت، تقسیم و تسویهٔ هزینه‌های گروهی است. اطلاعات به‌صورت محلی روی دستگاه کاربر ذخیره می‌شود و پس از اولین اجرا، برنامه آفلاین نیز کار می‌کند.

Repository: [github.com/WhoisGray/DongBan](https://github.com/WhoisGray/DongBan)

## قابلیت‌ها

- مدیریت چند رویداد مستقل برای سفر، مهمانی و خانهٔ مشترک
- دفترچهٔ اسامی ماندگار با `localStorage`
- ثبت هزینه با پرداخت‌کننده، تاریخ، دسته‌بندی، یادداشت و مصرف‌کنندگان
- تبدیل خودکار ارقام فارسی و عربی و افزودن جداکنندهٔ هزارگان هنگام ورود مبلغ
- سهم‌های مساوی و وزنی مانند `۰٫۵`، `۱` و `۲`
- تخصیص دقیق واحد پول با روش Largest Remainder؛ بدون گم‌شدن اعشار
- رُندکردن تسویه به نزدیک‌ترین ۱، ۱۰، ۱۰۰، ۱٬۰۰۰ یا ۱۰٬۰۰۰
- کمینه‌سازی دقیق تعداد انتقال‌ها تا ۱۰ ماندهٔ فعال و الگوریتم سریع برای گروه‌های بزرگ‌تر
- تحلیل هزینه‌ها بر اساس دسته‌بندی و نمایش وضعیت هر نفر
- جست‌وجوی رویداد و هزینه، تکثیر رویداد و حالت روشن/تیره
- خروجی و بازیابی کامل JSON
- کپی یا اشتراک‌گذاری خلاصهٔ تسویه
- PWA نصب‌پذیر، اجرای آفلاین و پشتیبانی از safe area در iPhone
- فونت ایرانی Estedad برای رابط و Lalezar برای تیترها، به‌صورت self-hosted و آفلاین
- route-level code splitting و vendor chunk مجزا
- تست واحد موتور محاسبه
- Docker و Docker Compose
- اتصال رسمی Vercel Analytics برای شمارش بازدیدها و page viewهای مسیرهای Vue

## اجرای توسعه

نیازمندی: Node.js نسخهٔ 20.19 یا جدیدتر.

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده توسط Vite (معمولاً `http://localhost:5173`) را باز کنید.

## تست و build

```bash
npm test
npm run lint
npm run build
npm run preview
```

خروجی production در پوشهٔ `dist` ایجاد می‌شود. Service Worker فقط در build نهایی فعال است.

## اجرا با Docker

```bash
docker compose up --build
```

برنامه روی [localhost:8080](http://localhost:8080) در دسترس خواهد بود. تنظیمات Nginx از مسیرهای Vue Router و cache فایل‌های fingerprint‌شده پشتیبانی می‌کند.

## نصب روی موبایل

### iPhone و iPad

1. سایت را در Safari باز کنید.
2. دکمهٔ Share را بزنید.
3. `Add to Home Screen` را انتخاب کنید.
4. روی Add بزنید.

### Android و Desktop

دکمهٔ «نصب اپ» را بزنید یا گزینهٔ Install را از منوی مرورگر انتخاب کنید.

برای نصب PWA در محیط واقعی، برنامه باید روی HTTPS منتشر شود؛ `localhost` برای توسعه استثنا محسوب می‌شود.

## معماری

```text
src/
├── components/     اجزای مستقل رابط
├── composables/    سرویس‌های اشتراکی رابط
├── stores/         state و persistence رویدادها
├── utils/          پول، تسویه، دسته‌بندی و شناسه‌ها
└── views/          صفحات lazy-loaded و code-split
```

مبالغ در کوچک‌ترین واحد صحیح ارز نگهداری می‌شوند. هزینه‌های غیرقابل‌تقسیم با Largest Remainder توزیع می‌شوند تا مجموع سهم افراد همیشه دقیقاً برابر مبلغ هزینه باشد. رُندکردن مانده‌ها نیز به‌صورت متوازن انجام می‌شود و مجموع نهایی همواره صفر باقی می‌ماند.

## حریم خصوصی

رویدادها، هزینه‌ها و دفترچهٔ اسامی در `localStorage` همان دستگاه ذخیره می‌شوند و به سرور برنامه ارسال نمی‌شوند. Vercel Analytics فقط آمار استفاده و page viewهای سایت را پس از استقرار جمع‌آوری می‌کند. برای انتقال اطلاعات بین دستگاه‌ها از بخش تنظیمات فایل پشتیبان بگیرید.
