# دنگ‌بان (DongBan)

دنگ‌بان یک Progressive Web App فارسی برای ثبت، تقسیم و تسویهٔ هزینه‌های گروهی است. اطلاعات به‌صورت محلی روی دستگاه کاربر ذخیره می‌شود و پس از اولین اجرا، برنامه آفلاین نیز کار می‌کند.

Website: [dongban.ir](https://dongban.ir)

Repository: [github.com/WhoisGray/DongBan](https://github.com/WhoisGray/DongBan)

## قابلیت‌ها

- مدیریت چند رویداد مستقل برای سفر، مهمانی و خانهٔ مشترک
- دفترچهٔ اسامی ماندگار با `localStorage`
- ثبت هزینه با پرداخت‌کننده، تاریخ، دسته‌بندی، یادداشت و مصرف‌کنندگان
- تبدیل خودکار ارقام فارسی و عربی و افزودن جداکنندهٔ هزارگان هنگام ورود مبلغ
- سهم‌های مساوی و وزنی مانند `۰٫۵`، `۱` و `۲`
- تخصیص دقیق واحد پول با روش Largest Remainder؛ بدون گم‌شدن اعشار
- رُندکردن تسویه به نزدیک‌ترین ۱، ۱۰، ۱۰۰، ۱٬۰۰۰ یا ۱۰٬۰۰۰
- کمینه‌سازی دقیق تعداد انتقال‌ها تا ۱۰ ماندهٔ فعال و الگوریتم سریع برای گروه‌های بزرگ‌تر
- تحلیل هزینه‌ها بر اساس دسته‌بندی و نمایش وضعیت هر نفر
- جست‌وجوی رویداد و هزینه، تکثیر رویداد و حالت روشن/تیره
- خروجی و بازیابی کامل JSON برای همهٔ داده‌های برنامه
- انتقال یک رویداد مستقل با Excel یا JSON و امکان Paste مستقیم JSON
- فایل Excel راست‌چین با شیت‌های جدا برای رویداد، اعضا، هزینه‌ها، سهم‌ها، مادرخرج‌ها، خلاصهٔ افراد و تسویه‌ها
- قالب نمونهٔ Excel/JSON و دستور آماده برای تکمیل فایل با AI
- کپی یا اشتراک‌گذاری خلاصهٔ تسویه
- PWA نصب‌پذیر، اجرای آفلاین و پشتیبانی از safe area در iPhone
- فونت ایرانی Estedad برای رابط و Lalezar برای تیترها، به‌صورت self-hosted و آفلاین
- route-level code splitting و vendor chunk مجزا
- تست واحد موتور محاسبه
- Docker و Docker Compose
- اتصال رسمی Vercel Analytics برای شمارش بازدیدها و page viewهای مسیرهای Vue
- تقویم شمسی اختصاصی برای رویدادها و هزینه‌ها
- کارت تصویری تسویه برای دانلود و اشتراک‌گذاری مستقیم
- اعلان آپدیت PWA، بررسی دوره‌ای و migration امن داده‌های نسخه‌های قبلی

## اجرای توسعه

نیازمندی: Node.js نسخهٔ 20.19 یا جدیدتر.

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده توسط Vite (معمولاً `http://localhost:5173`) را باز کنید.

## تست و build

```bash
npm test
npm run lint
npm run build
npm run preview
```

خروجی production در پوشهٔ `dist` ایجاد می‌شود. Service Worker فقط در build نهایی فعال است.

## اجرا با Docker

```bash
docker compose up --build
```

برنامه روی [localhost:8080](http://localhost:8080) در دسترس خواهد بود. تنظیمات Nginx از مسیرهای Vue Router و cache فایل‌های fingerprint‌شده پشتیبانی می‌کند.

## نصب روی موبایل

### iPhone و iPad

1. سایت را در Safari باز کنید.
2. دکمهٔ Share را بزنید.
3. `Add to Home Screen` را انتخاب کنید.
4. روی Add بزنید.

### Android و Desktop

دکمهٔ «نصب اپ» را بزنید یا گزینهٔ Install را از منوی مرورگر انتخاب کنید.

برای نصب PWA در محیط واقعی، برنامه باید روی HTTPS منتشر شود؛ `localhost` برای توسعه استثنا محسوب می‌شود.

## انتشار و آپدیت PWA

هر deploy جدید Service Worker تازه‌ای با hash فایل‌ها تولید می‌کند. نسخه‌های نصب‌شده هنگام بازشدن برنامه، بازگشت به foreground، وصل‌شدن اینترنت و سپس هر ۶۰ دقیقه آپدیت را بررسی می‌کنند. اگر نسخه‌ای آماده باشد، کاربر بنر «آپدیت الان / بعداً» می‌بیند؛ فعال‌سازی تنها پس از انتخاب کاربر انجام می‌شود.

نسخه، زمان build و شناسهٔ commit در صفحهٔ تنظیمات نمایش داده می‌شوند. ساختار ذخیره‌سازی یک کلید پایدار و migration زنجیره‌ای دارد؛ پیش از مهاجرت نسخهٔ قدیمی نیز یک backup اضطراری در `localStorage` ساخته می‌شود.

برای Vercel، فایل [vercel.json](./vercel.json) مسیرهای Vue Router و هدر بدون cache برای Service Worker و manifest را تنظیم می‌کند.

## انتقال رویداد با Excel و JSON

در صفحهٔ هر رویداد، دکمهٔ «انتقال داده» سه مسیر در اختیار کاربر می‌گذارد:

1. دانلود رویداد جاری به‌صورت Excel یا JSON و کپی JSON در کلیپ‌بورد
2. ورود فایل `.xlsx` یا `.json` و Paste مستقیم JSON
3. دانلود نمونهٔ تکمیل‌شده و کپی دستور پیشنهادی برای AI

ورود فایل همیشه یک رویداد مستقل جدید می‌سازد؛ رویداد فعلی بازنویسی نمی‌شود. اعضای فایل وارد دفترچهٔ اسامی محلی نیز می‌شوند. پردازش فایل کاملاً داخل مرورگر انجام می‌شود و فایل به سروری فرستاده نمی‌شود.

### شیت‌های Excel

| شیت | کاربرد | هنگام ورود خوانده می‌شود |
| --- | --- | --- |
| `راهنما` | قواعد تکمیل و دستور پیشنهادی AI | خیر |
| `رویداد` | عنوان، تاریخ، واحد پول و رُندکردن | بله |
| `اعضا` | `member_id` و نام اعضا | بله |
| `هزینه‌ها` | مبلغ، پرداخت‌کننده، دسته‌بندی، تاریخ و یادداشت | بله |
| `سهم‌ها` | اتصال هر هزینه به اعضا و ضریب سهم | بله |
| `مادرخرج‌ها` | تعداد هزینه و جمع پرداخت هر پرداخت‌کننده | خیر؛ محاسبه می‌شود |
| `خلاصه افراد` | پرداخت، سهم مصرف و ماندهٔ هر عضو | خیر؛ محاسبه می‌شود |
| `تسویه‌ها` | انتقال‌های پیشنهادی نهایی | خیر؛ محاسبه می‌شود |

همهٔ شیت‌ها RTL، دارای سربرگ ثابت، عرض ستون مناسب، فرمت عددی و اعتبارسنجی سلول‌های کلیدی هستند. شناسه‌های `member_id` و `expense_id` باید یکتا باشند و بین شیت‌ها دقیقاً تطبیق داشته باشند. مبلغ‌ها عددی و به واحد پول رویداد نوشته می‌شوند. تاریخ میلادی مبنای ماشین با قالب `YYYY-MM-DD` است و تاریخ شمسی نیز برای خوانایی در فایل نمایش داده می‌شود.

### قرارداد JSON رویداد

قرارداد فعلی با `format: "dongban-event"` و `schema_version: 1` شناخته می‌شود. بخش‌های قابل ورود عبارت‌اند از `event`، `members`، `expenses` و `shares`. بخش‌های `payers` و `calculated` گزارش هستند و هنگام ورود قابل اعتماد فرض نمی‌شوند؛ دنگ‌بان نتیجه را از داده‌های اصلی دوباره محاسبه می‌کند.

این تفکیک باعث می‌شود یک نفر فایل رویداد را برای شخص دیگری بفرستد، شخص دوم هزینه‌های جدید را اضافه کند و نسخهٔ نهایی را دوباره در گروه به اشتراک بگذارد، بدون نیاز به حساب کاربری یا بک‌اند.

## معماری

```text
src/
├── components/     اجزای مستقل رابط
├── composables/    سرویس‌های اشتراکی رابط
├── stores/         state و persistence رویدادها
├── utils/          پول، تسویه، دسته‌بندی و شناسه‌ها
└── views/          صفحات lazy-loaded و code-split
```

مبالغ در کوچک‌ترین واحد صحیح ارز نگهداری می‌شوند. هزینه‌های غیرقابل‌تقسیم با Largest Remainder توزیع می‌شوند تا مجموع سهم افراد همیشه دقیقاً برابر مبلغ هزینه باشد. رُندکردن مانده‌ها نیز به‌صورت متوازن انجام می‌شود و مجموع نهایی همواره صفر باقی می‌ماند.

## حریم خصوصی

رویدادها، هزینه‌ها و دفترچهٔ اسامی در `localStorage` همان دستگاه ذخیره می‌شوند و به سرور برنامه ارسال نمی‌شوند. Vercel Analytics فقط آمار استفاده و page viewهای سایت را پس از استقرار جمع‌آوری می‌کند. برای انتقال همهٔ داده‌ها از بخش تنظیمات فایل پشتیبان بگیرید و برای انتقال یک رویداد از دکمهٔ «انتقال داده» همان رویداد استفاده کنید.
